# Accessibility Audit — `index.html`

## Issues found and fixes

| Check | Finding | Fix or status |
|---|---|---|
| Page title | The document title was “Daisy Awuor - About Me,” although this is the home page. | Changed it to “Daisy Awuor | Home.” |
| Landmarks | The page content had no `header`, `main`, or `footer` landmarks. | Grouped the introduction in `header`, the photo and hobbies in `main`, and the links in `footer`. |        
| Images | The photo already had `alt="Daisy Awuor"`. | Kept the existing text alternative. |
| Headings | The page already used one `h1` followed by an `h2` for Hobbies. | Kept the heading hierarchy. |
| Document language | The document already declared `lang="en"` on `<html>`. | Kept the language declaration. |
| Form labels | There are no form inputs on `index.html`. | Not applicable to this page. The contact form has associated labels in `contact.html`. |
